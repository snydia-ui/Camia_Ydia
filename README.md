# ACTIVITY 4: HYPOTENUSE OF A RIGHT TRIANGLE FINDER PROJECT
## Description: 
Find the hypotenuse of a right triangle.
Using Pythagorean theorem, and 2 side lengths(A and B) that is given by the user(with `input()`).
Get the Hypotenuse
## How to open and run:
- Click on the .py file downloaded.
- Run the program using the play button.
- Input the side lengths that are asked for.
- Hypotenuse is given. Done.

## Inputs Needed
- Side length A
- Side length B
- `A = float(input("enter the length of the short side 1 of the triangle: "))`
- `B = float(input("enter the length of the short side 2 of the triangle: "))`
## Sample Outputs
- Hypotenuse - 5 Side Lengths - 3 & 4
- Hypotenuse - 13 Side Lengths - 5 & 12
